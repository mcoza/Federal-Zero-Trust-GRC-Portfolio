## Project background

This portfolio focused on enterprise security architecture to reduce unauthorized access in a civilian federal environment. The original academic project has been summarized into practical GRC deliverables.

The modeled domain includes internal users, privileged administrators, remote access users, application servers, file shares, logging systems, backup systems, network infrastructure, and segmented network zones.

## Portfolio purpose

The objective of this portfolio is to demonstrate entry-level GRC skills, including risk identification, control mapping, remediation tracking, policy development, and evidence planning.

## Expected outcome

This portfolio demonstrates how unauthorized access risk can be identified, mapped to controls, documented, and tracked through remediation in a federal Zero Trust-aligned environment.

## Core security themes by control type

### Management / Administrative controls

- Risk-based unauthorized access reduction
- Role-based access governance
- Audit-ready documentation
- POA&M-style remediation tracking

### Technical controls

- Privileged access separation
- Network segmentation and boundary protection
- Remote access control
- SIEM/logging visibility

### Operational controls

- Backup and restore validation
- Recurring access reviews
- Security event review
- Evidence collection and control validation
